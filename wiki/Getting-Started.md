# Getting Started with Assistant-Personnel-pour-la-Gestion-du-Temps

## 📋 Prerequisites
- **Python** 3.10+ / **Node.js** 18+
- **Git** & **GitHub CLI**

## ⚡ Quick Start
```bash
# Clone the project repository
git clone https://github.com/Bosaj/Assistant-Personnel-pour-la-Gestion-du-Temps.git
cd Assistant-Personnel-pour-la-Gestion-du-Temps

# Run the evaluation harness
python scripts/eval_harness.py

# Run the QA test suite
python -m pytest tests/test_monitoring_and_qa.py
```
